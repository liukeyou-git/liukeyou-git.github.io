## 前言

上一周用 Vipon 站外折扣码给新品链接注入了第一批真实订单与点击信号，亚马逊的搜索算法开始把这个 ASIN 和对应搜索词"对上号"。但站外推广有个天然上限：**折扣一停，流量立刻归零**。要让自然排名真正稳住，必须靠站内广告持续在搜索结果页"占位 + 转化"，把权重一点一点喂给自然位。

> **算法更新背景（2026）**：亚马逊的搜索排序已从早期"关键词匹配 × 销量"的 A9 时代，演进为 **A9（底层检索）+ COSMO（语义知识图谱，2024 年起叠加）+ Alexa for Shopping（原 Rufus，2026 年 5 月更名）** 的三层算法栈。卖家社区习惯统称"A10"，但亚马逊官方文档与 ACM SIGMOD 2024 论文里真正落地的是 COSMO。
>
> 这套新栈对广告策略的影响主要有三点：①**CTR 与 CVR 权重大幅上升**，主图和转化率比关键词密度更影响排名；②**外部流量成为一级排名因子**——一个外部销售对 velocity 的贡献约等于 3 个站内销售；③**语义相关性取代关键词匹配**，COSMO 能理解"keep my lunch warm"对应保温饭盒，即使 Listing 里没出现"lunch"。
>
> 这套变化不改变"广告推自然 → 自然位稳定 → 降广告依赖"的整体链路，但**对每一阶段的操作侧重有微调**——比如拓词阶段更要盯 CTR、防御阶段更要看外部流量质量。下面的四层策略都基于现行算法栈做了适配。

这周我把主要精力放在了系统学习亚马逊广告的全周期策略上。最大的认知更新是：**广告不是"开了就等出单"的烧钱工具，而是一条从"找词"到"稳位"的流水线**。关键词在广告体系里像产品在工厂里一样，要经历"拓词 → 预培养 → 强培养 → 防御"四个阶段，每一阶段的目标、广告结构、出价策略都不一样，错了阶段用错了策略，要么烧钱不出单，要么稳了的位又被竞品超车。

这篇文章把这条流水线讲清楚，重点是各阶段的**流转判定标准**和**Bid/Top/预算参数**，给同样在用广告推自然位的运营参考。

## 一、核心逻辑：广告是手段，流量结构转型才是终点

很多人对亚马逊广告的理解停留在"花钱买曝光 → 等点击 → 等转化"的层面，开个自动广告就盯着 ACOS 看。这种思路在新品阶段尤其危险，因为新品的转化率天然低，纯靠广告烧出来的订单成本高得吓人。

真正成熟的广告思维是把广告当作**自然位的"发动机"**，整个链路是这样的：

- **广告端**：抢占搜索结果流量入口，通过点击和转化累积关键词权重，把权重传递给自然位
- **自然位**：承接免费流量，逐步替代广告流量，整体流量成本下降，ACOS 随之下降
- **最终形态**：广告推自然 → 自然位稳定 → 降低广告依赖 → 利润最大化

这个逻辑的一个直接推论是：**广告 ACOS 不是越高越差**。在新品冲位阶段，ACOS 高是正常的，因为广告订单的"产出"不只是当次销售，还有它喂给自然位的权重。如果只盯着短期 ACOS 做调价决策，往往会把正在起量的关键词提前掐死。

所以判断广告效果的核心指标不是 ACOS，而是**自然排名是否在上扬**——只要自然位在动，广告烧的钱就是有产出的。

## 二、核心计算公式与调价原则

广告调价不是拍脑袋，背后有一套简单的公式在支撑。

| 指标 | 公式 / 原则 |
| :--- | :--- |
| 建议 CPC | `CVR × 商品售价 × 目标 ACOS` |
| 转化率 CVR | `购买量 ÷ 点击量` |
| 调价前提 | 点击量 ≥ 30-50 才有参考价值 |
| 前期策略 | 以"拿曝光 + 拿点击"为主，不盯着短期 ACOS |

举个具体例子：售价 $30、目标 ACOS 30%、CVR 10% 的话，建议 CPC = `0.10 × 30 × 0.3 = $0.90`。如果系统建议竞价是 $1.2，意味着按建议竞价跑 ACOS 大概率会超目标，需要把 Bid 压到 $0.9 附近测试。

这里有个新手常踩的坑：**点击量太少就开始调价**。我前面写 Listing 优化时就强调过"数据要有量才有意义"，广告也是一样。一个关键词跑了 5 个点击 0 转化，不代表这个关键词不行——5 个点击的样本太小，CVR 可能是 0，也可能是 60%，根本判断不出来。**至少跑够 30-50 个点击再判断去留**，否则就是数据噪音驱动的乱调。

## 三、生命周期流转总览：四层结构为什么是四层

把广告关键词按"自然排名位置 + 转化数据"两个维度划分，可以分成四个阶段：

| 阶段 | 自然位 | 关键词状态 | 核心目标 |
| :--- | :--- | :--- | :--- |
| 拓词层 | 无 / 极低 | 无权重 | 快速测试流量池，找有转化潜力的词 |
| 预培养层 | 80 名外 | 有少量转化数据 | 验证相关性，积累基础权重 |
| 强培养层 | 20-80 名 | 相关性已验证 | 暴力冲刺自然排名 |
| 防御层 | 前 20 名 | 自然流量承接力强 | 降本收割漏网流量，防超车 |

为什么非要分四层？因为不同阶段的关键词，需要做的事完全相反：

- **拓词阶段**：Bid 要低（避免烧钱）、Top 加成要低（前几位转化率反而差）、广告结构要散（自动 + Broad + Phrase 多组并行找词）
- **强培养阶段**：Bid 要高（必须抢到点击）、Top 加成要拉满（必须冲到搜索结果前几位）、广告结构要精（1 词 1 Campaign 集中火力）
- **防御阶段**：Bid 要降（自然位已经能接流量）、Top 加成归零（不需要广告位补）、广告结构要聚合（多词同组省管理成本）

如果所有关键词塞进同一个广告活动用同一套出价，结果是：新词抢不到曝光（被高 Bid 的老词挤掉），老词还在烧高价（其实自然位已经能接流量了）。**分层结构本质是让每个词在合适的阶段拿到合适的资源**。

## 四、拓词层：用最低成本快速测试流量池

### 阶段定义

关键词处于"无权重"或"权重极低"状态，目的是快速测试流量池，找出具备转化潜力的关键词。这个阶段**不要期待出单**，期待的是"数据"——哪些词有点击、哪些词有转化、哪些词光烧钱不转化。

### 广告结构

```
Auto（4组） + Broad（多词） + Phrase（多词）
```

- **Auto 拆 4 组**：Close Match / Loose Match / Substitutes / Complements 分别独立，便于后期根据表现单独调价
- **Broad 多词**：放长尾词和扩展词，跑出来什么词还能从 Search Term Report 里抓
- **Phrase 多词**：放核心词的词组匹配，平衡流量精度和量

### 操作策略

| 参数 | 取值 | 说明 |
| :--- | :--- | :--- |
| Bid | 建议竞价的 60%-100% | 按类型微调，Auto 可以更低 |
| Top of Search | 0%-30% | 拓词阶段不必强抢首位 |
| 预算 | $5-$30 | 单组预算，跑够数据就停 |

### 流转判定：什么时候算"找到了好词"

一个关键词从拓词层"毕业"进入预培养层，需要满足：

- **点击 ≥ 8-10**
- 且满足以下任一条件：
  - **订单 ≥ 2**
  - **CTR 高于平均**（说明词的相关性强）
  - **CVR ≥ 10%-15%**（说明转化潜力好）

达不到这些标准的词，要么继续在拓词层跑数据，要么直接否定掉（光烧钱不转化的词尽早止损）。

### 这个阶段最容易踩的坑

**坑 1：自动广告没拆组**

很多人开自动广告就一个活动包打天下，结果是 Close Match 跑得好被 Substitutes 拖累，整体 ACOS 看起来很差，但其实是有救的词被烂词稀释了。**Auto 一定要拆 4 组**，每组独立预算和出价，烂组直接停。

**坑 2：Bid 开太高，预算一两天就烧完**

拓词阶段最忌讳"上来就抢首位"。新品转化率天然低，Bid 拉满抢首位的结果是花 $2 一个点击买回来 1% 的转化，ACOS 直接爆表。**这个阶段的目的是"测试"，不是"转化"**，Bid 压到建议竞价 60% 左右先跑数据。

**坑 3：数据没跑够就否定词**

跑了一天 3 个点击 0 转化就把词否了，这是数据噪音驱动的决策。**至少给一个词 30-50 个点击的机会**，再判断去留。

## 五、预培养层：验证相关性与积累基础权重

### 阶段定义

关键词已有少量转化数据，但自然排名尚未显现或处于 80 名以外。这个阶段的核心是**验证相关性**（这个词是不是真的属于这个产品）和**积累基础权重**（让 A10/COSMO 算法在语义层面确认这个词和 ASIN 的关联）。

### 广告结构

```
精准匹配，1 词 = 1 Campaign
```

为什么必须 1 词 1 Campaign？因为精准匹配的目的是**精确控制单个词的曝光、点击、转化数据**。如果一个 Campaign 塞多个词，预算会被高 CTR 的词抢走，低 CTR 但有潜力的词永远拿不到数据。1 词 1 Campaign 看似管理成本高，但每个词的数据是干净的，调价决策才靠谱。

### 操作策略

| 参数 | 取值 | 说明 |
| :--- | :--- | :--- |
| Bid | 原 CPC + 10%-15% | 在拓词层 CPC 基础上小幅加码 |
| Top of Search | 20%-40% | 开始往搜索结果前部位置加码 |
| 预算 | $5-$20 | 单 Campaign 预算 |

### 流转判定：升级与降级

**升级到强培养层**：

- 自然位进入 20-80 名
- CVR ≥ 15%-20%
- 订单稳定（不是一次性爆款）

**降级回拓词层**：

- 长期点击高但无转化（相关性存疑，需要回拓词层重新跑）
- 数据反馈平平（既不爆也不死，可能是词的竞争太激烈，需要换长尾）

预培养层是整个流水线里**最容易被忽略的一层**。很多人从拓词直接跳到强培养，结果是出价拉满了但自然位起不来——因为词的相关性还没验证清楚，COSMO 不会给一个语义上"不确定属于这个产品"的词分配自然权重。新版算法对相关性的判断不再只看关键词是否出现，而是看词与 ASIN 的语义匹配度、CTR 与 CVR 的综合表现。

## 六、强培养层：暴力冲刺自然排名

### 阶段定义

关键词相关性已验证，自然排名处于上升期（20-80 名）。这个阶段是**最烧钱也最关键的一段**——通过广告暴力冲刺，把自然排名从前 80 名推到前 20 名。

### 广告结构

```
精准匹配，1 词 = 1 Campaign
```

和预培养层一样的结构，但出价策略完全不同。

### 操作策略

| 参数 | 取值 | 说明 |
| :--- | :--- | :--- |
| Bid | 原 CPC + 15%-30% | 出价上限拉到最高 |
| Top of Search | 30%-60% | 必须抢到搜索结果前几位 |
| 预算 | $10-$50 | 单 Campaign 预算 |

这一阶段的逻辑是：**自然排名 20-80 名时，自然流量很少，必须靠广告位补流量**。广告位带来的点击和转化累积权重，反哺自然位，自然位上升后再承接更多自然流量。这是一个"广告喂自然、自然反哺广告"的循环。

### 流转判定：升级与降级

**升级到防御层**：

- 自然排名稳定进入前 20 名
- 自然流量开始能稳定接单（不用广告位也能出单）

**降级回预培养层**：

- 自然位不升反降（说明竞品在反扑，需要重新验证策略）
- ACOS 失控（出价过高但转化跟不上，可能是 Top 加成开太猛抢到了不精准的位置）

### 强培养阶段的两个常见误区

**误区 1：Top 加成直接拉满 100%**

很多人以为 Top 加成越高越好，结果是广告位经常出现在搜索结果顶部，但顶部位置的点击率虽然高，转化率不一定比中部位置好（顶部位置容易吸引"随便看看"的点击）。**30%-60% 是个比较稳的区间**，既能抢到前几位，又不会因为出价过高烧穿预算。

**误区 2：自然位进了前 50 就停止加码**

自然位进入上升期是最容易松懈的时候，很多人看到自然位从 80 升到 50 就觉得"差不多了"，开始降 Bid。结果自然位在 50 名附近卡住上不去——因为 50 名的自然流量还是不够，广告一旦降火力，自然位立刻被竞品反扑。**强培养阶段必须盯到自然位稳定进入前 20 名才算结束**。

## 七、防御层：稳位收割，把广告成本降下来

### 阶段定义

自然排名已进入前 20 名，关键词已具备强大的自然流量承接能力。这个阶段的核心是**降低广告成本**——通过广告吃掉搜索结果里的漏网流量（那些没点到自然位的买家），防止被竞品超车。

### 广告结构

```
多词同组（精准匹配）
```

和前面两层的"1 词 1 Campaign"不同，防御层可以**多词同组**。原因是这些词的自然位都已经稳定，不需要每个词单独精细化管理，多词同组可以大幅降低管理成本。

### 操作策略

| 参数 | 取值 | 说明 |
| :--- | :--- | :--- |
| Bid | 稳定或小幅下调 | 不需要再加码 |
| Top of Search | 0%-20% | 自然位已经在前面，广告位不需要抢前几 |
| 竞价策略 | 动态竞价 - 只降低 | 让系统自动降那些转化差的出价 |

**动态竞价 - 只降低**是这个阶段的关键策略。它的逻辑是：亚马逊系统会根据每次点击的转化概率自动下调出价，转化概率低的点击降到更低出价，转化概率高的保持原出价。这比手动调价更精细，能省下大量广告费。

### 流转判定：降级回强培养

**降级回强培养层**：

- 自然位掉出前 20 名（说明竞品反扑成功了，需要重新加码冲刺）

### 防御阶段最容易犯的错

**错：防御层直接关掉广告**

很多人觉得自然位稳了，广告可以全停。结果是关广告的当周自然位就开始下滑——因为竞品一直在用广告位补流量，你停了广告等于把搜索结果前几位的曝光位让给了竞品。**防御层的广告不是"为了出单"，是"为了占位"**，必须维持最低限度的曝光。

## 八、ASIN 投放策略：除了关键词，还能打竞品

除了关键词广告，亚马逊还支持 ASIN 投放——直接把广告打到某个具体竞品 ASIN 的详情页下面。这个策略在关键词竞争激烈时尤其有用，可以从竞品详情页"截流"。

### 筛选条件

不是所有竞品 ASIN 都值得打。筛选标准：

- **点击 ≥ 5**
- **订单 ≥ 1**
- **ACOS 可接受**

也就是说，先从搜索词报告里找出"已经有点击和转化"的竞品 ASIN，再决定是否加码投放。**不要盲目打一堆 ASIN**，大部分 ASIN 投放出来都是无效曝光。

### 攻击优先级

筛选出候选 ASIN 后，按以下优先级投放：

1. **高价竞品**：抢性价比。你的产品比竞品便宜，详情页下方的广告位对你的转化率天然友好
2. **低评分 / 弱 Review 竞品**：抢转化。竞品 Review 弱，买家看到你的广告会点过来对比

反过来，**不要打低价高评分竞品**——你的广告位挂在它下面，买家对比完反而去买竞品了，等于给竞品送曝光。

### 设置参数

| 参数 | 取值 |
| :--- | :--- |
| Bid | 建议竞价的 80%-120% |
| 竞价策略 | 动态竞价 - 只降低 |

ASIN 投放的竞价策略和防御层类似，用"只降低"让系统自动优化出价。

## 九、子体选择策略：销量最高 ≠ 最适合打广告

如果一个父 ASIN 下有多个子体（比如不同颜色、不同尺码），广告投哪个子体是个常被忽略但很关键的决策。**销量最高的子体不一定是最适合打广告的子体**。

### 三种子体的分工

一个健康的变体广告策略，是把子体分成三类，各司其职：

| 子体类型 | 选什么 | 职责 |
| :--- | :--- | :--- |
| 流量子体 | 高 CTR（主图吸睛） | 低成本引流 |
| 转化子体 | 大众款 | 承接转化，喂养关键词权重 |
| 利润子体 | 高客单价款 | 收割利润 |

- **流量子体**选主图最吸引人、CTR 最高的子体，用低 Bid 拉流量进 Listing。买家进了 Listing 不一定买这个子体，但流量已经进来了
- **转化子体**选最畅销的大众款（比如经典黑、标准尺码），负责把流量转化成订单，喂养关键词权重
- **利润子体**选高客单价的款式（比如限定色、加绒款），负责收割利润

### 一个常见错误：频繁切换主推子体

很多人这周推 A 子体，下周看 B 子体销量好就切到 B，再下周又切回 A。结果是**权重无法累积**——A10/COSMO 算法对子体的权重是单独计算的，频繁切换等于每个子体都从零开始。

**确定主推子体后减少切换，保持权重连续性**。如果一定要切换主推子体，至少留 4-6 周的过渡期，让新主推子体的权重先起来再降旧子体的预算。

## 十、本周操作复盘与踩坑

### 关键参数对照表

把四层的核心参数汇总成一张表，方便日常调价时对照：

| 阶段 | 广告结构 | Bid | Top of Search | 预算 | 竞价策略 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 拓词层 | Auto(4) + Broad + Phrase | 建议 60%-100% | 0%-30% | $5-$30 | 固定或动态-升降 |
| 预培养层 | 1词1 Campaign（精准） | 原 CPC + 10%-15% | 20%-40% | $5-$20 | 固定或动态-升降 |
| 强培养层 | 1词1 Campaign（精准） | 原 CPC + 15%-30% | 30%-60% | $10-$50 | 动态-升降 |
| 防御层 | 多词同组（精准） | 稳定或小幅下调 | 0%-20% | 视情况 | 动态-只降低 |

### 这周踩的三个坑

**坑 1：拓词阶段开了一个"通用大组"自动广告**

刚开始图省事，开了一个包含所有匹配类型的 Auto 活动，结果跑了一周数据一团乱——Close Match 的转化被 Substitutes 稀释，整体 ACOS 看起来很差但分不清哪些词该留。后来拆成 4 组重新跑，第二天就看清了哪些词有潜力。

**坑 2：预培养层 Bid 加得太猛**

有个关键词在拓词层 CVR 12%，进入预培养层时我直接把 Bid 从 $0.8 拉到 $1.2（加 50%），结果预算两天烧完，CVR 反而掉到 8%——因为出价高了抢到的位置不精准，转化率反而下降。后来按规则只加 10%-15%，CVR 回到 12% 自然位也稳了。

**坑 3：自然位进前 20 就停了广告**

有个词自然位到 18 名时我以为稳了，直接停了广告，结果一周后自然位掉到 35 名。竞品一直在用广告位补流量，我停了等于把搜索结果前几位让给了竞品。**防御层的广告必须维持最低曝光**，自然位稳了之后是降 Bid，不是关广告。

### 后续两周的调整方向

基于这周的操作复盘，下一轮调整：

- **拓词层**：所有 Auto 拆 4 组，每周跑一次 Search Term Report 拉新词
- **预培养层**：Bid 调整幅度严格控制在 10%-15%，不再单次大幅调
- **强培养层**：盯到自然位稳定进入前 20 再降级，不卡在 30-50 名就提前松懈
- **防御层**：保留最低预算 + 动态只降低，广告 ACOS 控制在 15% 以下

## 结语

这周学完亚马逊广告全周期策略，最大的认知更新是：**广告不是单一工具，是一条流水线**。关键词在四个阶段之间流转，每个阶段需要做的事完全相反——拓词阶段要"散而广"，强培养阶段要"精而猛"，防御阶段要"省而稳"。

整体逻辑可以浓缩成三句话：

- **核心目标**：广告推自然 → 自然位稳定 → 降低广告依赖 → 利润最大化
- **流转判定**：每个阶段的升级和降级都有明确的数据标准（点击量、CTR、CVR、自然位位置），不要凭感觉调
- **分层管理**：1 词 1 Campaign 是预培养和强培养阶段的标准结构，多词同组是防御层的管理优化，别混用

承接上一周的 Vipon 站外推广思路，亚马逊站内广告是**让自然排名真正稳下来的最后一块拼图**。站外折扣码注入的是"销量信号"（在新算法下，一个外部销售对 velocity 的贡献约等于 3 个站内销售），让 A10/COSMO 算法把 ASIN 和搜索词在语义层面关联起来；站内广告注入的是"持续的点击和转化数据"，让自然位从前 80 推到前 20，再通过防御层稳住不下去。

新品冷启动从来不是一招制胜的事。从 Listing 优化、A+ 内容、Coupon + Vipon 站外推广，到这周的广告全周期策略，本质都是在用不同的工具给 A10/COSMO 算法喂不同的信号——点击信号、转化信号、外部流量信号、语义相关性信号。等自然排名起来之后，再逐步降低对广告和站外折扣的依赖，把流量入口切回站内自然搜索和 Alexa for Shopping 的 AI 推荐位——这才是广告在产品全生命周期里的真正定位。
